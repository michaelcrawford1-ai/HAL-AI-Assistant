# Portfolio Notes

This repository is a public-facing portfolio copy of the HAL AI Assistant project.

It is not intended to be a full raw mirror of the private development repository.

## Why this public copy exists

The private repository contains work that is useful for development but not appropriate for a public job-search portfolio, including:

- Private project coordination history
- Household-specific implementation notes
- Local machine configuration
- Operational details for automation services
- Issue and pull request discussions that were written for private collaboration
- Internal handoffs between AI tools

This public copy presents the architecture, design thinking, and engineering direction in a way that is appropriate for recruiters, hiring managers, and technical reviewers.

## What this demonstrates

HAL demonstrates applied work across several areas:

- AI-assisted workflow design
- Local-first system architecture
- Human-in-the-loop automation
- Technical documentation
- Security and privacy planning
- Product thinking
- Multi-agent coordination
- Review-gated software development
- Roadmap and scope management

## What is intentionally omitted

The following categories are intentionally excluded:

- Secrets and credentials
- API tokens
- Webhooks
- Local network details
- Private logs
- Private issue comments
- Private pull request discussions
- Sensitive personal context
- Household-specific operational data
- Any content that would make the private system easier to attack

## How to evaluate this project

For portfolio review, focus on:

1. The clarity of the architecture
2. The separation between product and build tooling
3. The use of explicit safety boundaries
4. The workflow design around GitHub state
5. The staged roadmap from assistant basics toward controlled automation
6. The practical tradeoffs between privacy, usefulness, and operational complexity

## Suggested future public additions

Good next additions to this public repo would include:

- A sanitized system diagram
- Example issue lifecycle
- Example decision-compression output
- Example review-gate checklist
- A small demo service or mock orchestrator
- Screenshots of sanitized project dashboards
